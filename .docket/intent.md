# slop-seattle

A browser-based New York City simulation built with three.js, WebGPURenderer and TSL. You can explore Manhattan on foot, by car, by bicycle or by helicopter, with traffic, pedestrians, buildings, trees, subway entrances and procedural audio. The app is static (index.html, js/, css/). Scripts in tools/ turn the NYC Open Data, MTA and OpenStreetMap extracts in tools/data/ into the generated geodata modules in js/. Tests are in tests/. It is unclear how this repo relates to Seattle: its name is slop-seattle, but the README and code still describe "Slop New York" and Manhattan, so it may be a fork meant to be adapted to Seattle.

## Paths agents must not touch

- `js/nyc-geodata.js`: Generated by tools/build-geodata.mjs; do not edit by hand
- `js/building-geodata.js`: Generated by tools/build-buildings.py; do not edit
- `js/building-geodata.bin.gz`: Binary asset generated by tools/build-buildings.py
- `js/tree-geodata.js`: Generated by tools/build-trees.py; do not edit
- `js/tree-geodata.bin.gz`: Binary asset generated by tools/build-trees.py
- `js/subway-geodata.js`: Generated by tools/build-subway-entrances.mjs; do not edit
- `tools/data/*.json`: Third-party source data extracts (NYC Open Data, MTA, OpenStreetMap) under their own licenses
